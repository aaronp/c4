How it works
  • One model, nested by heading depth: ## people and systems, ### containers, #### components.
  • Every element has a - slug:. Relationships point at dot paths like trading.orders.gateway.
  • Click + containers on a box (or double-click it) to drill in. Relationships roll up to whatever is visible.
  • Drag a box to move it; positions go to the # Layout section, relative to the parent.
  • Drag the orange dot onto another box to add a relationship between exactly those two.
  • Select a system or container, then use the Add buttons to add something inside it.
  • Delete or Backspace removes the selected box or relationship. Ctrl/⌘+Z undoes, Ctrl/⌘+Shift+Z redoes, for markdown and diagram edits alike.
